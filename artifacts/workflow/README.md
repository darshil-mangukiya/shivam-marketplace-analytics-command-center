# Operational Workflow Artifacts

`exception_queue.json` is generated by `python/run_workflow.py` from `product_action_review.csv` and `inventory_action_review.csv`.

The checked-in queue contains 290 high- or medium-priority exceptions in the initial `New` state. Stable exception IDs allow later refreshes to preserve status. No approvals or reviewer actions are prepopulated.

```bash
python python/run_workflow.py
```

Accepted status transitions can be recorded through `shared.workflow.transition_exception()` and `append_action_log()`. The action log is created when an actual transition is supplied.

Workflow records contain public product IDs, marketplace, recommendation fields, status, and workflow metadata.
