## Rules

- Capture screenshots from the **final Power BI report**, not from the Streamlit app.
- Include only public-safe content: public product IDs, grouped dimensions, indexes,
  percentages, scores, bands, recommendation labels, and validation summaries.
- Do **not** include raw or private data, private file paths, ASINs, seller SKUs,
  order IDs, listing IDs, product titles, postal codes, or exact raw financial values.
- Save real PNG files (file signature must match the `.png` extension).
