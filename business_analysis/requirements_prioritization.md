# Requirements Prioritization (MoSCoW)

## Must Have

- upload and public-output validation (BR-18–BR-20);
- marketplace and product performance (BR-01–BR-08);
- profitability and margin-risk labeling (BR-09–BR-10);
- inventory recommendations (BR-11–BR-13);
- deterministic variance analysis (BR-14–BR-17);
- privacy scanning and requirements traceability (BR-20–BR-22).

## Should Have

- KPI metadata alignment checks (BR-21);
- exception queue and append-only action log (BR-23–BR-24);
- rejection of invalid workflow transitions (BR-25);
- Azure SQL dimensional reporting model;
- Microsoft Fabric Bronze, Silver, and Gold processing.

## Could Have

- additional YAML contracts for the remaining public outputs;
- scheduled local refresh orchestration;
- a workflow summary inside the Streamlit interface.

## Future Scope

- marketplace write-back;
- streaming ingestion;
- multi-user authentication and role-based access;
- statistical forecasting or causal modeling.
